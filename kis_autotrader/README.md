# KIS 모의투자 자동매매

한국투자증권 Open API(KIS Developers)로 국내주식 **모의투자** 자동매매를 하는 Python 프로그램입니다.
전략은 이동평균선 크로스(기본 5일/20일) + 손절(-5%)/익절(+10%)입니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `gui.py` | **데스크톱 앱** (버튼·표·로그 화면) |
| `run_app.bat` | 더블클릭으로 앱 실행 (Python 설치 필요) |
| `build_exe.bat` | 앱을 `KIS_AutoTrader.exe` 로 만들기 |
| `main.py` | 명령줄(CLI) 버전 |
| `trader.py` | 점검·주문 핵심 로직 (앱/CLI 공용) |
| `strategy.py` | 매매 신호 계산 (여기만 고치면 전략 변경) |
| `kis_api.py` | 토큰·시세·잔고·주문 API 호출 |
| `config.example.yaml` | 설정 예시 |

## 설치
```bash
python -m pip install -r requirements.txt
```

## 앱 실행
- `run_app.bat` 더블클릭, 또는 `python gui.py`
- 처음 실행하면 **설정 창**이 뜹니다 → 모의투자 APP KEY / SECRET / 모의계좌번호 입력 → 저장
  (설정은 `config.yaml` 로 저장되며, 이후 [⚙ 설정]에서 언제든 수정)

### 화면 사용법
| 버튼 | 동작 |
|---|---|
| 🔌 연결 테스트 | 토큰·잔고·현재가 확인 (주문 없음) |
| 🔍 신호 확인 | 이동평균·매매 신호 계산 (주문 없음) |
| 🛒 지금 1회 실행 | 신호가 있으면 모의 시장가 주문 |
| ▶ 자동매매 시작 / ■ 중지 | 평일 장 시간에 설정한 주기(기본 5분)마다 자동 점검·주문 |
| ⚙ 설정 | 키, 관심종목, 전략, 리스크 설정 |
| 📂 기록 폴더 | 로그·거래기록(`trades.csv`) 폴더 열기 |

표에서 **빨강 = 매수 신호, 파랑 = 매도 신호**입니다.

## exe 로 만들기 (Windows)
1. `build_exe.bat` 더블클릭 → 1~2분 후 `dist` 폴더가 열림
2. `KIS_AutoTrader.exe` 더블클릭 (Python 없는 PC에서도 실행됨)
3. `config.yaml`, `logs` 는 exe 와 같은 폴더에 생깁니다
- 백신이 PyInstaller exe를 오탐지하는 경우가 있습니다. 그때는 예외 등록하세요.

## CLI 버전
```bash
python main.py --check     # 연결 테스트
python main.py --dry-run   # 신호만 확인
python main.py --once      # 1회 점검 + 모의주문
python main.py --auto      # 장 시간 동안 반복
```

## 안전장치
- 모의투자(`mode: demo`) 전용 — 실전 주문은 코드에서 차단
- 같은 종목은 하루에 한 번만 매수/매도
- 최대 보유 종목 수, 종목당 예산 제한
- 자동매매 중에는 설정 변경·수동 실행 불가 (중복 주문 방지)

## 자주 나오는 오류
| 메시지 | 원인 / 해결 |
|---|---|
| 토큰 발급 실패 | 모의투자 키가 맞는지, 실전 키를 넣지 않았는지 확인 |
| EGW00133 / 1분당 1회 | 토큰 재발급은 1분에 1회 제한. 잠시 후 재시도 |
| EGW00201 | 초당 호출 초과. 자동 재시도됨 |
| 계좌 관련 오류 | 계좌번호 뒤 2자리(보통 `01`) 확인 |

> ⚠ `config.yaml`, `.token_cache.json` 은 키 정보가 들어있으니 공유하거나 GitHub에 올리지 마세요.
