# 소방설비기사(전기) 실기 두문자 암기장

소방설비기사(전기) 실기 대비용 암기 웹앱입니다. 로그인이나 설치 없이 브라우저에서 바로 열리고, 한 번 열어 두면 인터넷이 없어도 열립니다.

## 바로 열기

- GitHub Pages 주소를 휴대폰·PC 브라우저에서 엽니다.
- 휴대폰에서는 '홈 화면에 추가'를 하면 앱처럼 쓸 수 있습니다 (아이폰은 사파리 공유 버튼, 안드로이드는 크롬 메뉴).
- `index.html` 파일 하나만 내려받아 열어도 동작합니다 (이 경우 글꼴만 기본 글꼴로 보일 수 있음).

## 구성

- **두문자 카드 100장** (10개 파트): 감지기, 경계구역·수신기·발신기, 수신기 시험·절연, 비상경보·방송·속보·가스, 누전경보기, 유도등·비상조명등, 비상콘센트·무선통신, 배선·비상전원, 제어반·가스계, 가닥수·시퀀스·공식
- **숫자 단답형 100문항**: 법령 문장의 수치를 빈칸으로 만든 문제, 입력 후 자동 채점
- **설치기준 서술형 89문항**: 기출 유형("~의 설치기준을 쓰시오")으로 만든 문제, 답안을 써 보고 정답과 비교

## 기능

- 보면서 외우기 / 가리고 떠올리기 모드
- 카드별 '외웠음', '다시 볼 것' 표시 (브라우저에 저장)
- 기록 내보내기·불러오기로 다른 기기에 옮기기
- 빈출 필터, 검색, 섞기, 시험일(2026-11-07) D-day
- 오프라인 동작(서비스 워커), 홈 화면 설치(웹 앱 매니페스트), 다크 모드

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 암기장 본체 (데이터·화면·동작 모두 포함) |
| `sw.js` | 오프라인 캐시. 내용을 고치면 `VERSION` 값을 올려야 새 버전이 내려감 |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 설치용 정보와 아이콘 |

## 기준

- 화재안전기술기준(NFTC) 현행본
- 자동화재탐지설비(NFPC 203)는 2026-03-01 시행 개정 반영
- 도로터널은 NFPC·NFTC 603, 지하구는 NFTC 605 (지하구 문항은 교재와 한 번 대조 권장)
- 2026-05-04 개정 고시(NFPC 201·205·304·504·505·602)의 세부 변경은 법령정보센터에서 확인 필요
