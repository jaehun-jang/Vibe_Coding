# 소방설비기사(전기) 실기 두문자 암기장

소방설비기사(전기) 실기 대비용 암기 웹앱입니다. HTML 파일 하나로 되어 있어 별도 설치 없이 브라우저에서 바로 열 수 있습니다.

## 구성

- **두문자 카드 100장** (10개 파트): 감지기, 경계구역·수신기·발신기, 수신기 시험·절연, 비상경보·방송·속보·가스, 누전경보기, 유도등·비상조명등, 비상콘센트·무선통신, 배선·비상전원, 제어반·가스계, 가닥수·시퀀스·공식
- **숫자 단답형 100문항**: 법령 문장의 수치를 빈칸으로 만든 문제, 입력 후 자동 채점

## 기능

- 보면서 외우기 / 가리고 떠올리기 모드
- 카드별 '외웠음', '다시 볼 것' 표시 (브라우저에 저장)
- 빈출 필터, 검색, 섞기
- 시험일(2026-11-07) D-day 표시
- 다크 모드, 모바일 화면 지원

## 사용법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 없으면 글꼴만 기본 글꼴로 표시됩니다.

## 기준

- 화재안전기술기준(NFTC) 현행본
- 자동화재탐지설비(NFPC 203)는 2026-03-01 시행 개정 반영
- 2026-05-04 개정 고시(NFPC 201·205·304·504·505·602)의 세부 변경은 법령정보센터에서 확인 필요
